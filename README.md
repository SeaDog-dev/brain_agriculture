# Brain Agriculture

Aplicação para gerenciamento de produtores rurais, propriedades agrícolas,
culturas plantadas e indicadores relacionados ao uso do solo.

## Tecnologias

- Node.js
- TypeScript
- NestJS
- PostgreSQL
- Prisma
- Jest
- Swagger/OpenAPI

## Funcionalidades

- Cadastro de produtores rurais
- Cadastro de propriedades
- Cadastro de culturas
- Associação de culturas às propriedades e safras
- Validação de CPF/CNPJ
- Validação das áreas da propriedade
- Dashboard com indicadores agrícolas
